# FX EASY

一个Minecraft 26.1.2 NeoForge Mod

在游戏中加入了炒外汇（FX）的玩法，还有神秘订阅档次，模拟盘涨跌幅度可配置，玩家可以在各种法币物品的汇率变化中交易获取利益

此外还移植了安格瑞模组的物品与方块：安格瑞方块（普通/闪电/原子）、母安格瑞方块、安格瑞之刃、长矛、神枪、法杖和安格瑞陨石召唤器，以及对应的三维法杖/召唤器模型、方块模型粒子、陨石实体和后处理效果；世界生成未移植。法杖可从附近方块汲取安格瑞能量获得临时生命值（以安格瑞红心接在生命条后作为额外生命值显示），松手时消耗一半并释放安格瑞狂潮。安格瑞陨石召唤器由安格瑞方块 OBJ 与 Blaze3D 长杖拼合而成，方块位于杖尖，右击地面即可从天上召唤一颗大号安格瑞方块陨石，落地爆炸并在坑中留下成片安格瑞方块，其中混有闪电与原子变体。
